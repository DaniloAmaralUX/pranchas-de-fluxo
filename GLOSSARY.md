# Vocabulário do Pranchas

- **Catálogo** é a coleção de telas e demonstrações do Supernova que a pessoa pode explorar.
- **Tela de referência** é uma tela do catálogo escolhida por uma característica que ajuda no desenho, como composição, densidade ou hierarquia.
- **Base de design** é a combinação de referências selecionada para um pedido.
- **Pedido** reúne o material recebido para uma geração e, quando escolhida, sua base de design.
- **Briefing** reúne o problema, os papéis, as evidências e as perguntas em aberto.
- **Fluxo** é o percurso que uma pessoa segue para concluir uma tarefa. Pode incluir alternativas e exceções.
- **Prancha** é o desenho técnico de uma tela, com peças que podem ser inspecionadas.
- **Requisito** é aquilo que a pessoa precisa poder fazer ou compreender naquela tela.
- **Evidência** é o trecho do material de origem que fundamenta a regra de negócio.
- **Contrato de desenho** é o conjunto de condições verificáveis que uma entrega precisa cumprir para ser selada.
